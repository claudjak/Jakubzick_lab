# Jakubzick Lab website

The website of the Jakubzick Laboratory (Claudia Jakubzick, Department of Microbiology and Immunology, Geisel School of
Medicine at Dartmouth): **https://claudjak.github.io/Jakubzick_lab/**

It replaces the WordPress site at geiselmed.dartmouth.edu/jakubzick and keeps its content (research program, people,
publications, contact), restyled after the [CANlab](https://torwager.github.io/canlab/) and
[scienceofplacebo.org](https://scienceofplacebo.org) sites, with a searchable tagged publication database, reference
export, a collaborator map, bibliometrics, and an automated daily search for new papers.

- **Static site** in `site/` (no build step for the HTML; JSON data and pre-rendered paper pages are generated by `pipeline/build_site.py` into `site/data/` and `site/papers/`).
- **Data** as plain JSON in `data/`: `papers.json` (the bibliography: every PubMed record with Claudia Jakubzick as an author, plus book chapters), `people.json`, `research.json`, `news_posts.json`, plus `candidates.json` / `screened.json` written by the daily search and `news.json` by the news search.
- **Tags** on three axes (`pipeline/taxonomy.json`): topic, approach, article type; see `pipeline/prompts/classify.md`.
- **Daily search** (`.github/workflows/daily.yml`): OpenAlex author works + PubMed author query, LLM tagging, a review queue (`data/candidates.json`), citation refresh, site rebuild and deploy.
- **News** every two days (`.github/workflows/news.yml`): Google News RSS, optional LLM relevance filter.
- **Hero graphic** (`site/assets/hero.js`): an interactive field of macrophages, dendritic cells and monocytes; the cursor acts as a chemokine source, clicks release a chemokine burst and trigger phagocytosis.

## Local use

```bash
pip install -r requirements.txt
python -m pipeline.build_site                 # writes site/data, site/papers, feed.xml, sitemap.xml
(cd site && python -m http.server 8765)       # http://localhost:8765
```

Editing content: change the JSON files in `data/` (people, research themes, news posts) and push; the site rebuilds and
deploys automatically. Paper records live in `data/papers.json`; tags, `summary`, `key_finding` and `free_keywords` can
be edited by hand and survive re-tagging.

```bash
python -m pipeline.run_daily --days 30 --dry-run     # try the search locally (needs an LLM key for tagging)
python -m pipeline.approve --list                     # review queue
python -m pipeline.approve <id> [<id>...]             # promote candidates into papers.json
python -m pipeline.news --no-llm                      # news search without the LLM filter
```

## One-time setup

1. **Pages**: Settings → Pages → Source "GitHub Actions". The daily workflow deploys `site/`.
2. **Secrets** (Settings → Secrets and variables → Actions): `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` (tagging and the news filter; without a key the daily search still runs and queues untagged candidates), optionally `OPENALEX_API_KEY` and `NCBI_API_KEY`. Variables: `JLAB_CONTACT_EMAIL` (polite-pool email for OpenAlex/PubMed), `JLAB_LLM_MODEL` (default `claude-sonnet-5` / `gpt-5-mini`).
3. **Analytics** (optional): create a site in Cloudflare Web Analytics and paste the token into `cfAnalyticsToken` in `site/assets/config.js`.
4. **Search engines**: submit `https://claudjak.github.io/Jakubzick_lab/sitemap.xml` in Google Search Console.

## Provenance

`scripts/import_pubmed.py` built the initial `papers.json` (September 2026) from PubMed and OpenAlex; `scripts/make_tag_bundles.py`
and `scripts/apply_tags.py` were used for the first tagging pass. Photos and figures in `site/assets/img` and the gallery
come from the lab's earlier website and from the lab's open-access papers (credits in `site/assets/gallery/credits.json`).
